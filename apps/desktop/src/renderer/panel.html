NJYN.AI Meeting Notes

Set up

One of these two, and you are recording. Everything else already works.

1 Paste an API key

Fastest way to a first note. One Groq key covers both transcription and the summary, and a long meeting costs a couple of cents.

Put it in this file, then hit Reload .env:

~/.njyn/.env

GROQ_API_KEY=gsk_...
or
2 Install offline mode

Downloads whisper.cpp and the medium model (about 1.5 GB) into ~/.njyn. After this, audio never leaves this machine — only the optional summary needs a key.
